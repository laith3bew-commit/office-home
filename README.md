# Office Home

Offline-Familienbüro für Windows: Vorgänge, Fristen, Dokumente, Verträge und Briefe nach DIN 5008.

- Alle Daten bleiben lokal auf dem Computer. Dieses Repository enthält nur das Programm, keine Daten.
- Installieren: unter „Releases“ die neueste `OfficeHome-Setup-<version>.exe` herunterladen.
- Updates: Das installierte Programm sucht beim Start selbst nach neuen Versionen. Manuell geht es über „Einstellungen“ → „Programm-Update“.

## Entwickeln
```
npm install
npm start          # Programm ohne Installation starten
npm run dist       # Setup.exe bauen (dist/)
```
